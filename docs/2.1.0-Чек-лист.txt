True TV Launcher2.1.0 — короткая проверка на телевизоре
Сначала используйте отдельную папку Download/Проверка с копиями ненужных файлов. Для каждого пункта отметьте ОК/ошибка и модель/Android.

[ ] Обновить APK поверх2.0.6: рабочий стол/настройки на месте; в строке «О лаунчере» видно2.1.0.
[ ] Открыть «Файлы» верхней кнопкой-папкой или из настроек. Разрешить доступ к памяти. Слева дерево, справа строки; войти в папку/Назад, проверить USB при наличии.
[ ] Только пультом: имя → ⋮ → галочка; вверх/вниз по длинному списку; из последнего элемента строки вправо к шапке, затем вниз обратно. Фокус заметен и один. Долгий OK открывает меню без открытия файла; MENU/верхняя ⋮ работают и в пустой папке.
[ ] Новая папка; переименовать файл/папку; свойства показывают путь, тип, размер и дату.
[ ] Копировать → другая папка → Вставить. Повторить: совпавшее имя получает номер, прежнее содержимое не меняется. Проверить открытием, а не только появлением имени.
[ ] Вырезать/переместить → Вставить; проверить содержимое и исчезновение источника. Остановить большую копию: источник остаётся, незавершённый файл не появляется под окончательным именем.
[ ] Отметить несколько файлов; «Выделить всё» включает также строки за экраном текущей выборки. Снять выделение; поиск ограничивает выборку. Скопировать и удалить только тестовые копии с подтверждением.
[ ] Открыть файл; «Открыть с помощью»: подходящие приложения, однократно/запомнить. Повторное открытие через сохранённую связь; если обработчика нет — понятное сообщение.
[ ] «Отправить» один и несколько файлов через доступное приложение. Это обычное Android Share; пункт Wi-Fi показывает «позже» и ничего не передаёт. Папки пока нужно архивировать внешним приложением.
[ ] Из эмулятора «Browse for file»: выбрать ROM. «Browse for folder»: выбрать папку, затем перезапустить эмулятор и снова прочитать файлы. При наличии редактора проверить «Открыть документ»/«Создать документ» и запись. Если запрос всё ещё не открывается — записать имя/версию приложения и точный пункт.
[ ] Системные приложения: иконки, поиск, серое заметное выделение верхних кнопок; Подключение → инструкция/разработчик, разрешить выбранный ADB либо уже имеющийся root, проверить подключение.
[ ] Сначала на необязательном пакете: короткий OK в подтверждении ничего не запускает; удержание3сек выполняет выбранное отключение/включение/удаление; отпускание раньше сбрасывает. После операции проверить состояние в системе и лаунчере. Удаление всех профилей оставляет заводской APK; физическое удаление — отдельный root-пункт.

Особо опасные проверки — только с планом восстановления. Удаление заводского APK доступно лишь на подходящем уже записываемом разделе без enforcing AVB. Копия сохраняет APK, НЕ данные приложения. Проверить резервную копию/восстановление до её удаления. При замене OEM Home сначала должно успешно назначиться True TV Launcher; при отказе старый Home не трогается. Перезагрузка может понадобиться для обновления системного списка. Сам лаунчер и пакет android защищены.

Автоматическая проверка на эмуляторе не заменяет эти проверки на Beelink/Grundig. Android30+ ограничивает корни дерева и Android/data/obb. Жёстко заданный чужой компонент проводника не заменяется обычной регистрацией intents. Wi-Fi/телефонный ассистент, скрытая настройка A11y и применение ИК-карты отложены.

True TV Launcher 2.0.3 — сетка, фокус и подключение ADB
03.11.2026. Пакет ru.truetv.launcher, code203, minAPI21 / targetAPI34.

Установка
APK устанавливается поверх True TV Launcher2.0/2.0.1/2.0.2. Пакет и сертификат прежние; рабочий стол и настройки не очищаются. Simple Launcher Reborn в проекте22 — отдельное приложение, не менялся. Предыдущий полный2.0.2 сохранён.

Исправления по фотографиям
Сетка больше не сжимается в центр по высоте квадратных ячеек: шаги строк и столбцов независимы, вся доступная область используется. Изображение квадратное, рамка с отступом6dp; подпись при включении резервируется снизу. Убрана дополнительная штатная Android-подсветка всей ячейки поверх своей рамки. Верхние значки и часы выровнены по внешним изображениям, при тесном экране учитывается минимальное место под кнопки/дату/часы.
Adaptive-иконки рисуются исходными слоями в скруглённом квадрате без круглой маски OEM. Обычные иконки сохраняют пропорции. Рендер192dp с пределом256px для чёткости и ограничением кэша6MiB. Серая полупрозрачная панель меню сохранена. Перезапуск — классическая дуга с соединённым угловым наконечником по образцу старой синей панели.
В менеджере системных приложений: иконки40dp с асинхронной загрузкой и защитой повторного использования строк; fallback, если ОС не отдаёт изображение. Кнопки «Подключение»/«Обновить» явно выделяются светлым фоном с тёмным текстом. Подсветка строки списка исчезает, когда фокус пульта уходит на верхние элементы.
Исправлена настоящая ошибка Android Conscrypt: OpenSSLRSAPrivateKey нельзя приводить к RSAPrivateCrtKey. Публичные параметры читаются из сохранённогоPKCS8, приватный ключ принимает JCA; прежний файл/идентичность сохраняются. Ничего не сбрасывается ради исправления.

Подключение ADB
В меню «Подключение» добавлены «Как подключить ADB / root» и «Параметры разработчика».
1. Откройте параметры разработчика. Если раздел скрыт: настройки устройства → Об устройстве → семь нажатий на «Сборка».
2. Включите «Отладка по сети» / «ADB по TCP/IP», если такой пункт есть. Только USB-отладка не обязательно открывает сетевой порт.
3. В лаунчере выберите ADB и адрес этого же устройства: обычно127.0.0.1:5555; используйте обычныйTCP-портADB, показанный прошивкой.
4. Нажмите «Проверить подключение», подтвердите системный запрос RSA.
5. Если пункта сетевой отладки нет, может понадобиться однократный adb tcpip 5555 с компьютера через USB либо имеющийсяroot. Приложение не может само включить отладку.
Поддерживается legacyRSA, сопряжение кодом/TLS пока не поддерживается. Порт современной Wireless debugging сюда не подходит. При закрытом порте/тайм-ауте есть понятное пояснение.
Root: уже должен быть установлен. Выберите соответствующий способ, проверьте подключение и разрешите доступ в менеджереroot. Параметры разработчика/ADB для этого способа не нужны.

Проверки и ограничения
Сборка/подписьv1v2, прежний сертификат, code203,185собственных runtimeклассов, без старых классов/TTF/so, CRC/alignment ресурсов — PASS. Host84domain+35expert+18008геометрия/RSA — PASS,180конфигураций экранов/сеток, включая5×4,7×5,малые размеры и4K.
Android9/API28:18нативных проверок PASS. Подтверждены повторное чтение RSA Conscrypt и подпись прежнему publickey, формы иконок, ширина сетки, размер64dp/отступ6dp, отсутствие двойной подсветки, загрузка списка с иконками, перемещение фокуса, контраст верхних кнопок и DpadRight→Refresh. Установка202→203 принята. Финальные скриншоты просмотрены. Это отдельный одноразовый эмулятор, не Sony/Grundig.
В промежуточном прогоне локальный портADB эмулятора не слушал послеadb tcpip: ECONNREFUSED, реальные ADB-сессии/мутации этим тестом не подтверждены. ИсправлениеRSA подтверждено отдельно от сети. Ещё один прогон прервал системныйANRdialog, после его закрытия финальные18проверок прошли. Bluetooth выключен только в тестовыхprefs, в этот прогон не проверялся. После проверки эмулятор переведён вUSB и остановлен.
Физические Sony/Grundig, реальныйroot-менеджер и обычная A11yForceStop остаются неподтверждёнными этим выпуском. Backend мутаций/ControlService не изменены. Наличие сетевой отладки и команд зависит от прошивки. Защита core/self/Home/IME и подтверждение каждого экспертного изменения сохранены; удаление только для текущего пользователя с сохранением данных, APK прошивки остаётся.

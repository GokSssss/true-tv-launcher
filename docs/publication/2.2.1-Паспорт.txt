05.11.2026. Проект22.1, прежняя подпись, обновление поверх существующих APK.

Что изменилось
На рабочем столе после файлового менеджера — антенна. Она открывает окно приёма, которое сразу начинает слушать локальную сеть. Уход из окна/Home/Закрыть прекращает приём, текущий сокет и обнаружение. Нет постоянного приёмного сервиса, overlay-разрешения, boot receiver или доверенных устройств.
Галочка «Принимать без подтверждения» по умолчанию выключена: на входящий файл Принять/Отклонить. Если включить, все новые передачи принимаются автоматически только пока это окно открыто. Значение галочки сохраняется, однако само по себе не открывает приём.
После файла: Открыть файл / Показать в папке / Закрыть. Папка — публичный Downloads. Для нескольких файлов Open предлагает выбрать имя. Open передаёт read-only content URI, нужен обработчик этого типа файлов. Показать открывает встроенный файловый менеджер, которому могут понадобиться его обычные разрешения хранилища. Любой выход прекращает приём.
На телефоне To TV доступен только из меню Отправить, без своей иконки. Выбрать ТВ и смотреть прогресс. Нет первого диалога с кодом и запоминания доверия. TLS всё равно проверяет ключ выбранного mDNS-получателя. Android показывает обязательное уведомление отправляющей foreground-службы; фонового TV-приёма нет.

Границы
Одна локальная сеть, mDNS, без интернета/ADB/root/A11y. Wi-Fi или Ethernet на ТВ. Изоляция гостей/multicast-фильтр мешает обнаружению. Размеры long, поток64KiB, SHA256 перед публикацией, MediaStore29+ или hidden staging21–28. Коллизии создают отдельные имена. При отмене текущий незавершённый файл удаляется, готовые остаются; возобновления нет. Открытие отправителя на том же физическом ТВ закрывает его окно приёма: отправляйте с другого устройства.

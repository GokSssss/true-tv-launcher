True TV Launcher2.0.2 — расширенные функции и системные приложения
03.11.2026. ru.truetv.launcher, versionCode202, minAPI21/targetAPI34.

Установка
Установите 2.0.2-True-TV-Launcher.apk поверх2.0/2.0.1. Пакет/сертификат сохранены, данные настроек и рабочий стол не очищаются. Предыдущий полный2.0.1 сохранён. Simple Launcher Reborn в проекте22 — отдельное приложение, не изменялось.

Изменения
Вместо произвольного редактора порядка — раздел «Расширенные функции контекстного меню» и одна галочка со значками закрытия/перезапуска. «Закрытие и перезапуск в начале списка»: включена — эти два действия первыми, выключена — оба на прежних местах. Она не скрывает пункты. Пояснение о ручном включении специальных возможностей. «Открыть приложение» в долгом нажатии отсутствует; свойства остаются последним действием. Наконечник перезапуска в конце дуги по касательной, разрыв после него.
Нижний раздел «Расширенные возможности для опытных пользователей»: поиск системных пакетов, отключить/включить, удалить для текущего пользователя с сохранением данных (-k), восстановить заводскую установку. Оба выбранных владельцем метода — ADB и имеющийсяroot. Сам APK прошивки не удаляется даже черезroot. Перед каждым изменением подтверждение с пакетом/методом/пользователем.
ADB: legacyRSA, без pairingcode/TLS, отладку по сети нужно включить/разрешить самостоятельно. Проверяется подключение к тому же устройству одноразовым локальным файлом; при невозможности проверки запись блокируется. Приватный RSAключ хранится во внутренней памяти приложения. Root: только уже установленныйsu и разрешение пользователя, проверкаuid0. Нет установкиroot или скрытого включения отладки. Нет произвольной shellконсоли: закрытые команды, валидация package/user, ограниченные время/вывод. Защищены core/persistent/свойпакет/текущийHome/IME; зависимые функции других пакетов могут пострадать. После команды проверяются код выхода и точное состояние, после ошибки список тоже обновляется. INTERNET добавлен только ради явно запрошенногоADB, нет рекламы/аналитики/автоматической сети. Обычные A11yдействия отдельно, не используют эти привилегии.
ИК-пульты BeelinkGT1/Grundig обсуждались отдельно: универсальные профили только для распознаваемых приёмником кодов; переназначение не реализовано в этом выпуске.

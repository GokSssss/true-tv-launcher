True TV Launcher2.1.0 — Файловый менеджер и системные приложения
04.11.2026. ru.truetv.launcher, code210, minAPI21/target34. Общий APK, встроенный File Manager, без отдельной установки модуля. Обновление поверх2.0.6 сохраняет рабочий стол/настройки, постоянная подпись прежняя.

Основные функции
Дерево папок слева, один список справа: оригинальные контурные значки, имя/тип/размер/дата, ⋮, галочка. Только пульт; долгий OK/⋮/MENU открывает файловые операции. Нижней панели нет. Копировать/вырезать/вставить/переместить/новая папка/переименовать/удалить/отправить/свойства/выделить всё. При совпадении имени новый номер. Staging и отмена копирования; источник перемещения удаляется после готовой копии. Файлы/папки первичной памяти и доступных USB, без обхода приватных каталогов/символьных ссылок. Отправка файлов — Android Share, архивирование папок не реализовано. Открытие по MIME/сохранённой связи расширения с подходящим установленным приложением.
Собственные DocumentsProvider и picker: GET_CONTENT, OPEN_DOCUMENT, OPEN_DOCUMENT_TREE, CREATE_DOCUMENT, несколько файлов, реальные content URI/допуски. На телевизоре без DocumentsUI обслуживаются стандартные implicit-запросы. Это не подмена жёстко заданного чужого компонента. Допуск OPEN/TREE/CREATE можно сохранить; GET_CONTENT временный. О лаунчере всегда показывает2.1.0 прямо в строке.
Wi-Fi/телефонный ассистент отложены: только пункт «Передача по Wi-Fi — позже», без сервера/обнаружения/передачи. Скрытая настройка A11y и применение ИК-карты не добавлены.

Установка и доступ
Открыть Файлы верхней кнопкой-папкой или из настроек, разрешить доступ к памяти. Android23–29 READ/WRITE_EXTERNAL_STORAGE; Android30+ вручную «Доступ ко всем файлам», закрытые Android/data/obb не обходятся. Ограничения выбора дерева корня/Download действуют на новых Android. Старые функции/темы/сетка/ИК-диагностика сохранены.
В экспертном менеджере Подключение → ADB либо уже имеющийся root → инструкция/Параметры разработчика → проверить. ADB legacyRSA с ручной сетевой отладкой и подтверждением, без TLS pairing; проверяется именно локальное устройство. Root требует uid0.
Удаление установок всех профилей оставляет заводской APK в прошивке. Для физического удаления есть отдельный root-пункт только на уже записываемой прошивке без enforcing AVB. Проверяются точные APK и пакет, сохраняется проверенная резервная копия APK, данные приложения в неё не входят. Без автоматического remount/AVB/boot-изменений. Восстановление APK/удаление копии — Подключение → Резервные копии удаления. Может понадобиться перезагрузка для обновления системного списка.
Для опасных действий/«Всё равно…» непрерывное OK3сек. Отпускание/смена фокуса сбрасывает таймер. Перед изменением текущего Home сначала назначается и проверяется True TV Launcher; при отказе старый сохраняется. Сам инструмент/android не удаляются. Копия APK не восстанавливает утраченные данные.

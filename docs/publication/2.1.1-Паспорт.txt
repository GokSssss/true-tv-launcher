True TV Launcher2.1.1 — Файловый менеджер: дерево и выбор
04.11.2026. ru.truetv.launcher, code211, min21/target34. Обновление поверх2.1.0 тем же ключом, рабочий стол/настройки сохраняются. Один общий APK.

Что изменилось
Заголовок текущей папки над правым списком; N выбранных из M в текущей выборке, число файлов/папок. Дерево с соединительными линиями. По явному выбору владельца постоянная колонка между деревом и списком: Добавить папку, Добавить TXT, Свойства папки, Выбрать всё, Снять выделение, Вставить. Нет нижней панели.
В строках убраны кнопки ⋮ и пустые checkbox. Галочка только у выбранного элемента, его рамка и фон сохраняются при уходе пульта. Контекстное меню: Выбрать/Снять выделение, открыть, операции с точным именем или типом группы файлы/папки/файлы и папки. В обычном долгом нажатии НЕТ Новой/Добавить папку и Добавить TXT. Отправить и отложенный Wi-Fi только у файла/группы только файлов, отсутствуют у папок/смешанных групп.
Копировать в буфер → открыть назначение → Вставить в постоянной колонке. После Копировать/Вырезать отметки снимаются, обычный OK снова открывает назначение. Вставка подписывает объекты и папку назначения. Обычный OK открывает, при отметках переключает выбор; контекстное Открыть доступно независимо. Внешний picker сохраняет свои ограничения выбора/допуски.
Из любой строки Left сразу колонка, ещё Left дерево, Right обратно с сохранённой прокруткой. Right из списка шапка, Down назад. Верхняя кнопка со словом Меню и единым серым выделением/светлым текстом.

Сохранённые функции и ограничения
Файловые операции/провайдер/picker из2.1.0 сохранены; Android разрешения нужны. Стандартные implicit OPEN_DOCUMENT/GET_CONTENT/TREE/CREATE, content URI, persistable grants; жёстко заданные чужие системные компоненты не подменяются. Android30+ доступ ко всем файлам/ограничения Android/data/obb. Wi-Fi и телефонный ассистент по-прежнему НЕ реализованы; только пункт-заглушка для файлов, глобальная настройка Позже сохранена.
Системное удаление/ADB/root/A11y/ИК не расширялись. Физическое factoryAPK-удаление и OEM/USB/Android30+ требуют отдельной проверки; этот выпуск не заявляет их нативной проверки на приставке.

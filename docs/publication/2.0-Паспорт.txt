True TV Launcher 2.0 — первая самостоятельная сборка для проверки
Дата: 03.11.2026. Пакет: ru.truetv.launcher. versionCode: 200.
Android: minAPI21, target/compileAPI34. Формат: обычный подписанный APK, без root/Shizuku/ADB в лаунчере.

Установка
Скачайте 2.0-True-TV-Launcher.apk и установите как отдельное приложение. Старый Simple Launcher Reborn удалять не нужно: пакеты и ключи разные. Настройки старого пакета автоматически не переносятся. Перед выбором True TV Launcher основным Home проверьте его на телевизоре. Рабочий проект22 сохранён без изменений.

Что сделано
Новые исходники и ресурсы, собственный скруглённый жёлтый логотип и контурные значки. Сетка до7×5; одна настройка размера иконки, автоматические квадратные ячейки, компактная рамка по образцу владельца. Каталог/плюс/замена используют один поиск и галочку системных приложений, выключенную по умолчанию. Фиксированные иконки и три строки подписи с нижним отступом.
Полупрозрачные контекстные меню и подменю настроек, навигация пультом по кругу. Версия выбранного приложения справа от названия. Открыть/перезапустить можно ставить первыми; свойства — последнее действие перед Отменой. Удаление доступно из обоих меню через системное подтверждение.
Серые действия остаются фокусируемыми и открывают специальные возможности. Одна галочка индикаторов сама запрашивает Usage access. «Снять ограничение настроек» поясняет, когда оно нужно, и открывает внешний TVAccess либо свойства для ручного допуска. Внешняя утилита TVAccess1.1 исправлена отдельно; она использует собственное явно разрешённое ADB-подключение, в лаунчер не встроена.
Верхняя панель: кнопки без фона, Bluetooth с фиксированным счётчиком, VPN ON в две строки, дата перед часами меньшим шрифтом, три стиля часов/даты, дата словами/через slash/скрыта. Рекомендации Activity, поиск, кнопка «Показать всё» справа, сохранение подтверждённого перехода и запроса после «Выбрать другой».

Проверки и ограничения
Портативная сборка ECJ/D8/aapt2/apksig, подпись v1/v2, аудит APK PASS. 122 runtime-класса в ru.truetv.launcher; нет исходных старых классов/библиотек, TTF/OTF/so; resources.arsc stored/aligned4, INTERNET отсутствует.
84 domain-проверки PASS. Эмулятор Android14/API34: 28 основных и16 дополнительных проверок интерфейса PASS, включая поиск/системную галочку/единый плюс/геометрию иконок/циклическое меню/допуски/версию приложения/реальный переход Bluetooth и возврат с сохранением запроса. Основные28 повторены после изменения рамки. Последняя правка ControlService не меняла эти интерфейсные файлы.
ВАЖНО: фактическая остановка и перезапуск процесса интеграционным тестом пока НЕ подтверждены. Служба не подключилась внутри instrumentedprocess, хотя обычный запуск подтверждает Bound service в ОС. Это не пройденный тест; причина расхождения стенда не установлена. Физический Grundig новой реализацией не проверен. Сохраните старый лаунчер для возврата.
Остановка реализована через вручную включённую A11y-службу и системные свойства выбранного приложения, с проверкой идентичности/FLAG_STOPPED и тайм-аутом45сек. До физической проверки не обещается одинаковая работа на всех OEM-экранах. Службы автоматически не включаются.
Зелёная точка означает подтверждённый ОС процесс в памяти, включая кэш; не означает воспроизведение. Без Usage access/доступного системного API неизвестность не угадывается. Количество Bluetooth зависит от разрешения Nearby devices и доступных профилей. Системный статус-бар и имя владельца VPN могут быть недоступны прошивкой. Сон зависит от поддержки ОС; выключение/перезагрузка открывают штатное меню для ручного выбора.

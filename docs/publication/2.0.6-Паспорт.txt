True TV Launcher 2.0.6 — «Загрузки» и рамка навигации
03.11.2026. Пакет ru.truetv.launcher, code206, minAPI21, targetAPI34.

Установка
Обновление поверх2.0.5 тем же постоянным сертификатом. Рабочий стол и настройки сохраняются. Предыдущий полный2.0.5 сохранён; проекты22/24, личные ключи и права не менялись.

Отчёт в общих «Загрузках»
Отчёт → Сохранить в «Загрузки». Файл IR-diagnostic-yyyyMMdd-HHmmss-SSS.txt создаётся в общей папке Download. Старые файлы не перезаписываются. На Android23–28 первый запрос сохранения запрашивает READ/WRITE_EXTERNAL_STORAGE; оба разрешения объявлены только до maxSdk28. При отказе нет скрытой копии в Android/data, показывается объяснение. Android21–22 получает эти разрешения при установке. Android29+ использует MediaStore.Downloads без широкого разрешения: создать pending-запись, записать/закрыть, опубликовать; при ошибке удалить только свою незавершённую запись. Root, системный файловый выборщик и произвольные shell-команды для сохранения не нужны. Путь/имя показаны после успеха.

Выделение рабочего стола по фото
В Тёмной/Чёрной темах у выбранной иконки голубовато-серый полупрозрачный фон0x805e83aa, светлая рамка0xb3c3deea, небольшое скругление4dp. Постоянный отступ вокруг иконки8dp вместо6dp. Сетка сохраняет независимые шаги по полной доступной ширине и высоте. Фиксированный размер иконки остаётся заданным; автоматический вписывается в оставшееся место. Размер и положение не прыгают при переходе фокуса. Каталог, контекстные меню и экспертные серые кнопки этим изменением не перекрашивались.

Проверки и ограничения

Финальный APK:17 проверок IrUiCheck PASS на отдельном Android9/API28. Файл действительно создан в /storage/emulated/0/Download, прочитан обратно, проверено содержимое и отсутствие private fallback, затем удалён только тестовый файл. Разрешения для положительного теста выданы shell на одноразовом эмуляторе; ручной системный диалог не автоматизировался.
До исправления разрешений два прогона выявили Permission denied при WRITE-only; эти отчёты сохранены. В финале добавлен READ с maxSdk28 и проверкой обоих допусков, частичный отказ не зацикливает запрос. До запуска тестов закрыто наблюдаемое SystemUI ANR окно эмулятора. Первая установка истекла по времени до завершения загрузки VM, не является результатом теста приложения.
LayoutCheck:18 PASS на кандидате206 до последней правки манифеста/доступа к файлам. Tile/DesktopGeometry после этих проверок не менялись. Фиксированный/автоматический вид рабочего стола просмотрен на скриншотах. Финальный экран экспорта также просмотрен. Нативный Android29+ provider, физический Sony/Grundig и сохранение на настоящей GT1 этим прогоном не проверялись. Старые ограничения A11yForceStop/ADB/root системного менеджера сохраняются.

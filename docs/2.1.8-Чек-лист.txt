Порядок / Сортировка
[ ] В правой колонке короткое Порядок. На первом запуске От новых к старым, по дате изменения.
[ ] Последний изменённый файл/папка сверху; равные даты — устойчивое имя. Дерево по алфавиту.
[ ] От старых к новым, имя А–Я и Я–А меняют порядок. В диалоге одна radio-отметка; Отмена не меняет режим.
[ ] Выбранный режим сохраняется после закрытия/перезапуска. Выделенные файлы остаются отмеченными после сортировки.
[ ] Назад всегда первая строка внутри папки, нет в корне; в счётчик не входит. Поиск сохраняет порядок.

Исправления217 — сохранённые проверки
[ ] Плюс → выбрать приложение → оно сразу в выбранной ячейке; повторить в другой ячейке. Закрыть/открыть лаунчер: обе плитки сохранились. Проверить также после обновления поверх216, без очистки данных.
[ ] Одиночный/быстрый двойной Home: не мигает сетка, курсор и плитки остаются. Настройки → Лаунчер по умолчанию: статус показывает фактически назначенное приложение.
[ ] Если системный выбор не сохраняется: Лаунчер по умолчанию → Назначить True TV Launcher через ADB → подтвердить. Это отдельная команда, не выполняется автоматически. После подтверждённого результата проверить Home из другого приложения и после перезапуска приставки. Android5–6: системный выбор, ADB-назначение не заявлено.
[ ] Снять ограничение настроек открывает встроенный TV Access. В Подключении прочитать инструкцию, включить доступную отладку на самой приставке, указать её ADB-адрес/порт, разрешить RSA и проверить соединение. Наличие отладки USB не гарантирует сетевой порт; Android11+ беспроводное TLS-сопряжение этим клиентом пока не поддерживается.
[ ] Выделение конкретной службы само ничего не включает. Нажать Включить через ADB, прочитать имена и подтвердить. После успешного результата служба реально включена; уже включённые другие службы остались. Android13+ сначала снимается ограничение выбранных пакетов; ниже13 этот app-op не используется.
[ ] Если нужно только разрешить ручное включение: Разрешить выбранные приложения — это отдельная кнопка, не равна включению службы.
[ ] Подключение → Отключить выбранные службы → подтвердить. Выбранная выключается, остальные сохраняются. Не отключать нужные вам службы для галочки в тесте.
[ ] При отказе/нет соединения/неподдерживаемой команде показана ошибка, не ложное сообщение об успехе. Без включённой и разрешённой отладки ADB-функции не работают.
[ ] До начала выбора файлов нет Выбрано0/M. Выбрать один — счётчик появился; снять последнюю отметку/Назад — исчез, файловый менеджер остался открыт. Порядок не разбивает последнюю букву на строку.

Совместимость: приложение универсальное, min Android5, target Android14. Проверки эмуляторов не заменяют проверку OEM/физического телевизора. Не удаляйте рабочий системный лаунчер ради проверки Home.

Основная проверка218: плюс и возврат на рабочий стол
[ ] Обновить без удаления данных. На старте через значок и через Home открывается тот же рабочий стол с прежними иконками/настройками, версия2.1.8.
[ ] Плюс открывает список приложений поверх рабочего стола. Выбрать приложение: окно выбора закрывается, иконка сразу в выбранном месте, фокус на ней. Настройки и выбранное приложение сами не открываются, сообщения Добавлено на пустом экране нет.
[ ] Назад в выборе — отмена, ячейка осталась пустой. Home в выборе — рабочий стол без записи. Повторный плюс работает.
[ ] Заменить приложение работает через такой же список в той же ячейке. Проверить пакет с запуском и пакет без MAIN (для второго свойства открываются только по отдельному новому OK на плитке).
[ ] Открыть настройки лаунчера → Home → плюс → выбор. После выбора именно рабочий стол, без возврата в настройки.
[ ] Не отпускать OK резко/проверить обычное повторение ИК-пульта: остаточный сигнал после выбора не запускает новую плитку. Отпустить, затем новым OK открыть её — запуск работает.
[ ] Повторить добавление в несколько разных ячеек; закрыть/открыть лаунчер и проверить сохранение. Иконки/поиск/переключатель системных в списке выглядят как в обычном меню приложений.
[ ] Светлая/тёмная/чёрная тема и системные обои применяются и к окну выбора. Язык автоматически ru/en; отдельной настройки языка нет.
[ ] Закрытие/перезапуск через службу возвращает на рабочий стол/запускает выбранное приложение; чужие приложения не затрагиваются. Не проводить проверку на критичных системных компонентах.

Точное белое OEM-полотно на устройстве владельца по фотографии не воспроизведено. На VM проверяются окно выбора, реальные клавиши, тип задач, сохранение и возврат; после установки на телевизоре важно проверить первые три пункта.

Проверки218: Android9 —86native и2сценария закрытия/перезапуска, реальный Dpad. Android14 — новый218 прогон заблокирован сбоем стенда до установки APK. Исторические проверки217 на14 не заменяют эту проверку.

# ИК-пульт: границы первого этапа

Версия2.0.6; первый этап появился в2.0.5. Задача владельца — непосредственно управлять BeelinkGT1 другим ИК-пультом, например Grundig. Это не CEC и не переназначение уже распознанных Android-клавиш. Реальный способ требует сведений о встроенном приёмнике, его драйвере и прошивке; модель приставки сама по себе этого не определяет.

Выполнено: отдельный экран внизу настроек, явный запрос имеющегося root и проверка uid0. Только чтение фиксированных известных путей конфигурации/интерфейса Amlogic, Name/Handlers устройств ввода и отфильтрованных ИК-строк dmesg. Для отчёта не сохраняются Phys/Uniq, серийный номер или общий журнал ядра. Не вызывается очищающий журнал `dmesg -c`. Объём каждого root-ответа ограничен64KiB, конфигураций8192байт, ИК-строк80; root-запрос20сек, остальные4–5сек. Работа в одном фоновом потоке; при выходе задача прерывается и процесс чтения завершается.

Черновик:12действий, в том числе стрелки, OK, Назад, Домой, громкость. Два новых совпадающих диагностических кода в течение20сек после приглашения, затем ручное подтверждение. Для полного32бит NEC-кадра проверяется инверсия байта команды; протокол по неизвестному кадру не угадывается. Команда без адреса сохраняется как `?:ff`. Ручной ввод строго ограничен форматом; ни введённый текст, ни строки журналов не попадают в shell-команду. Хранение в частных SharedPreferences, без автоприменения. Отчёт — копирование или файл в общей папке «Загрузки», с датой/временем в имени. Android21–28 пишет в public Downloads (на23–28 разрешение при первом сохранении, READ/WRITE_EXTERNAL_STORAGE ограничены maxSdk28). Android29+ создаёт pending-запись MediaStore.Downloads, пишет и публикует, при ошибке удаляет только свою незавершённую запись; доступ к системному DocumentsUI не требуется.

**Не выполнено и не должно обозначаться работающим:** установка/активация профиля в драйвер, чтение произвольного протокола, автоматическое включение debug, изменение remote.conf, remount, загрузчика/DTB, аппаратного включения из сна или перехват пульта во всех приложениях. Для этого нужен отчёт с устройства и отдельный совместимый адаптер с резервной копией/откатом. В205 нет кнопки применения, которая могла бы создавать ложное впечатление успеха. Нулевой результат чтения не доказывает несовместимость: журнал может быть выключен либо формат неизвестен. Наличие remote.conf также не доказывает, что активный драйвер использует его.

Передайте отчёт, затем можно определить подходящий следующий этап. Смена протокола/карты вслепую может лишить управления старым пультом; в205 такая операция отсутствует. Для будущего применения нужны известные действующие карта/loader, проверка сохранённой копии, отдельный способ управления и временный профиль с гарантированным откатом; этого пока нельзя подтвердить на GT1.

## Публичные источники форматов

- [Khadas Android IR](https://docs.khadas.com/products/sbc/vim3/applications/ir): Android9, карта в DTS и keylayout. Подтверждает, что универсального редактирования одного файла для всех Android Amlogic нет.
- [CoreELEC: создание remote.conf](https://github.com/CoreELEC/remotes/wiki/02.-Amlogic%3A-Creating-remote.conf-from-scratch): описания NEC/кодирования. Это Linux-проект; `ir-keytable` не выдаётся за готовое Android-приложение.
- [Практический Android-разбор приёмника](https://blog.ayra.eu.org/blog/use-any-ir-remote-for-1725137912): опубликованные примеры `invalid custom`, `framecode`, remote.cfg/tab. Не доказательство совместимости с конкретной GT1, поэтому команды установки не выполняются.
- [Khadas, обсуждение доступа к IR](https://forum.khadas.com/t/ir-sensor-data-access-for-khadas-vim3/20202): зависимость диагностических узлов от версии драйвера. Интерфейс не предполагается существующим на всех устройствах.

Источники использованы как описание форматов/ограничений. Их код/конфигурации/бинарные инструменты не включены в приложение. Проверки host и эмулятора отделены от ещё не выполненной проверки настоящего root/ИК-приёмника GT1.


Отчёт владельца,03.11.2026: GT1u / Android9 SDK28 / PI.2603 release-keys. Root uid0 подтверждён самим отчётом. meson-remote, /sys/class/remote/amremote и /sys/class/rc, /vendor/bin/remotecfg, remote.cfg и remote.tab1–3 присутствуют. Активен NEC, debug_enable0; таблицы имеют custom_code fb04/fe01/bd02. В журнале есть `scancode 88/188/84/82 undefined`, без доказательства, от какого пульта они получены. Не угадывать десятичное/hex представление или адрес по одной строке. Системная карта не менялась; применение/откат остаются следующим этапом. Исходный отчёт в Документации, код/таблицы производителя не копируются в ресурсы APK.

True TV Launcher2.2.0 + To TV1.0.0 — проверка передачи

Установка
1. Телевизор: обновить True TV Launcher поверх прежней версии, данные не удалять.
2. Телефон: установить отдельный APK To TV. Значка обычного файлового менеджера у него нет: открывается через меню «Отправить».
3. Телевизор: Настройки → Передача файлов по Wi-Fi → Включить приём. На Android5–9 разрешить запись в хранилище, на новых версиях для Downloads используется MediaStore. Разрешить уведомления, если Android спросит.
4. Для кнопок поверх браузера разрешить «Показ поверх других приложений». Без этого открыть уведомление To TV для подтверждения запроса.
5. Оба устройства подключить к одной локальной сети. Телевизор может быть подключён кабелем, телефон — Wi-Fi. Изолированная гостевая сеть/запрет multicast могут мешать обнаружению; интернет не требуется.

Передача
6. В любом файловом менеджере телефона выбрать файл или несколько → Отправить → To TV → выбрать телевизор. При первом соединении сверить код на телефоне и телевизоре и подтвердить получателя на телефоне.
7. На TV проверить пять вариантов: Принять; Отменить; Принимать с устройства всегда; Принимать с устройства всегда в фоне; Принять этот файл в фоне.
8. «Принять» — окно прогресса с Отменить/Продолжить в фоне. «Этот раз в фоне» убирает окно, но не сохраняет доверие.
9. Оба «Всегда» запоминают ключ устройства. Следующая передача от него принимается автоматически; вариант «в фоне» не открывает окна. Доверенные устройства можно забыть в настройках передачи.
10. Полученные файлы должны появиться в общих Downloads с точным содержимым. При совпадении имени старый файл не меняется — создаётся другое имя.
11. Попробовать двоичный файл/архив/ROM, пустой TXT, несколько файлов и большое видео. После принятия убрать телефонное окно или выключить экран: передача должна продолжиться через foreground-службу.
12. Проверить Отменить до приёма и во время передачи: завершённые файлы остаются, незавершённый не публикуется. При обрыве связи сохранение всей партии не обещается — повторная отправка создаёт новые имена.
13. Перезагрузить TV после включения приёма: приёмник должен снова быть доступен, если прошивка допускает автозапуск службы. Выключить приём в настройках — TV должен исчезнуть из списка.
14. В файловом менеджере лаунчера пункт «Отправить по Wi-Fi» доступен только для файлов; папки сначала упаковать в архив.
15. Проверить, что при выключенной передаче рабочий стол, плюс/добавление, настройки, Home и файловые операции остались прежними. При включённом, но простаивающем приёмнике нет удержания CPU и активного опроса телевизоров.

Нет ADB, root и специальных возможностей для передачи. Новая функция не исправляет системный MediaProvider или ограничения конкретной прошивки. Эмуляторные проверки и физическая проверка на вашей паре телефон/телевизор фиксируются отдельно.

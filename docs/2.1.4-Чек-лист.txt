True TV Launcher2.1.4 — проверка новых правок
Используйте папку с копиями ненужных файлов и вложенной папкой.

[ ] Обновить поверх2.1.3; настройки/рабочий стол сохранены, О лаунчере показывает2.1.4.
[ ] Сменить язык Android ru/en: интерфейс автоматически русский/английский; на других языках английский. Имена файлов/папок неизменны.
[ ] Несколько раз отметить/снять отметку: курсор остаётся на последнем файле, в том числе далеко в списке и после popup/Отмены.
[ ] OK на корне Память устройства и USB сворачивает/разворачивает дерево. Рамка названия не пересекает линии веток.
[ ] Выбрать несколько → Назад: отметки сняты, папка/прокрутка сохраняются; ещё Назад работает обычно.
[ ] Колонки уже, строки плотнее, длинные подписи переносятся в2строки; между командами разделители. Справа от названия крупно Выбрано N/M. Имя новой папки заранее Новая папка.
[ ] В папке первым пунктом Назад: перейти к родителю. В корне устройства/USB пункта нет; в пустой папке он остаётся. Выбрать всё не отмечает Назад и не считает его файлом. Up с первого файла — на Назад, Down обратно.
[ ] Над центральным списком название текущей папки, отдельно путь. После входа/Назад заголовок меняется.
[ ] Между тремя колонками вертикальные разделители, в правой у каждого действия свой контурный значок. Слева дерево с соединительными линиями; в центре файлы, справа ПОСТОЯННЫЕ действия папки. Нет нижней панели.
[ ] В колонке Добавить папку и Добавить TXT действительно создают объекты в текущей папке. TXT получает .txt; свойства относятся к текущей папке.
[ ] В долгом OK на файл И на папку нет Добавить/Новая папка и Добавить TXT. Есть Выбрать/Снять выделение. В строках нет кнопок ⋮ и пустых checkbox.
[ ] Выбрать файл и папку: галочки только у отмеченных строк, рамка/фон остаются при уходе курсора; сверху Выбрано N из M плюс число файлов/папок. Снять одну отметку, снять все.
[ ] Выбрать всё в длинном списке включает элементы за экраном. Поиск ограничивает выборку. Вправо из далёкой строки сразу действия, влево обратно с прежней прокруткой; влево из файлов дерево, вправо из дерева файлы. Вправо из действий шапка, вниз обратно.
[ ] Кнопка Меню со словом и заметным серым фоном при фокусе, читаемым текстом. В меню операции с именем файла; группы отдельно файлы/папки/файлы и папки.
[ ] Копировать/Вырезать → открыть папку назначения → Вставить из колонки. Подпись вставки называет объекты и папку назначения. Проверить содержимое; совпавшие имена не затираются. Переименовать/удалить только тестовые копии.
[ ] Отправить и Wi-Fi есть у файла/группы только файлов. У папки и смешанной группы нет обоих пунктов. Wi-Fi сообщает Позже, ничего не передаёт.
[ ] Открыть с помощью, сохранить связь, повторить. Из внешнего приложения выбрать один/несколько файлов и папку; после перезапуска внешнего приложения повторно прочитать доступ.

Остальные функции системного удаления/ROOT/A11y/ИК не расширялись. Физическое root-удаление APK и особенности телевизора остаются отдельной проверкой; этот чек-лист не требует удаления системных APK.

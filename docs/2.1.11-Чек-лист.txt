True TV Launcher 2.1.11 — короткая проверка на телевизоре
Установить поверх 2.1.10 без удаления данных.

1. Настройки → Снять ограничение доступа к специальным возможностям.
2. Выбрать службу True TV Launcher в списке.
3. Перейти к первой строке списка и нажать Вверх: фокус должен оказаться на первой кнопке «Включить через ADB», а не на третьей. Подключение и изменение доступа от одного движения фокуса не выполняются.
4. Вправо — «Подключение ADB», Вниз — обратно в список. Галочка выбранной службы сохраняется, рамка курсора списка должна исчезнуть при переходе к кнопкам.
5. На Android9 для включения использовать именно «Включить через ADB». Третья кнопка снимает отдельное ограничение Android13+, которого на Android9 нет.
6. После подтверждения включения дождаться результата. При успехе проверить строку службы в настройках лаунчера. В окне результата OK просто закрывает окно; скрытый OEM-список служб открывать не требуется.
7. Если включение не подтверждено, сохранить точный текст результата. Отказ назначения главного экрана и включение службы — разные операции.
8. Назначение Home: если прошивка всё ещё выбирает штатный com.google.android.tvlauncher с priority2, будет понятное объяснение. Простое назначение не отключает штатный Home. Для заморозки: Системные приложения → штатный Home → «Всё равно отключить / заморозить» → непрерывное удержание OK три секунды. Если переключение на True TV не подтверждено, прежнее состояние штатного Home должно восстановиться. Перед этим тестом сохраняйте доступ к ADB с компьютера, если он у вас уже настроен.

Физическое устройство этой сборкой ещё не проверено. Новые проверки Android14 не заявляются. Связанные файловые операции, громкость, defaults и рабочий стол не перерабатывались.

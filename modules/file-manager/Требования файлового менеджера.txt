Обязательная схема после уточнения владельца
Платформа подтверждена: горизонтальный телевизор, только кнопки пульта как основной способ. Слева дерево папок, в центре один список содержимого выбранной папки, справа постоянные действия с папкой. Это не два независимых файловых каталога. В строчном виде справа только строки, никаких карточек или постоянной нижней области описания. Строка: иконка, имя (тип/размер/дата второй строкой), пассивная галочка только у отмеченных элементов. Кнопок ⋮/пустых checkbox в строках нет. Фокус и отметка файла различаются.
Операции с выбранными файлами во всплывающем меню по долгому OK либо верхнему Меню: копировать, вырезать, вставить, переименовать, удалить, отправить, выделить всё, свойства. Снятие выделения доступно при отмеченных файлах. Никакой нижней панели действий: она недоступна без прокрутки длинного списка и отклонена владельцем. Пустая папка также должна позволять открыть меню папки с Вставить/Новая папка — через дерево/верхнюю ⋮/кнопку MENU, без фиктивного файла. Вырезание не удаляет источник до успешного перемещения.
Навигация: вверх/вниз по видимым строкам, переход между деревом и списком; строка имеет одну область фокуса; выбор через контекстное меню, при активных отметках коротким OK. Из списка влево дерево, вправо действия; дальше вправо шапка. OK открывает папку/файл либо переключает галочку; удержание открывает меню и не запускает файл одновременно. Назад закрывает меню или возвращает к родителю. Всплывающее меню доступно с текущего файла при любой длине списка; навигация меню циклическая. Последний элемент строки имеет быстрый переход вправо к шапке; возврат вниз к запомненной строке. Так поиск и верхнее подтверждение выбора доступны без прокрутки каталога к началу. При возвращении восстанавливать строку/прокрутку, не переносить фокус в конец списка. Галочки допускают несколько файлов, «Выделить всё» — все элементы текущей выборки каталога с учётом поиска, типа и разрешений клиента, включая строки за пределами экрана; не другие каталоги или скрытые неподходящие файлы. Действия над группой имеют заголовок «Выбрано N». Сверху списка всегда N из M.
Тёмный фон, крупный читаемый текст, ясный серый фокус, простые контурные значки. Состояние текущей папки в дереве не маскировать под второй активный курсор.

Главная функциональная цель
Помимо встроенного файлового менеджера нужен совместимый выбор файла/папки для других приложений, включая эмуляторы наTV без DocumentsUI. В2.1.0 реализованы собственный DocumentsProvider и отдельное окно выбора, которое обрабатывает стандартные запросы Android. Поддержать открытие одного/нескольких файлов, выбор папки и создание документа; возвращать content URI и корректные допуски к выбранному документу/дереву. Один DocumentsProvider не создаёт отсутствующий picker. GET_CONTENT и OPEN_DOCUMENT — разные договоры доступа; согласовать их регистрацию без двойных пунктов/самовызова. Сохранённые допуски и реальные чтение/запись через ContentResolver требуют проверки на отдельном клиенте после перезапуска. Не возвращать вместо рабочего URI сырой путь file://.
Нельзя обещать прозрачную замену приложению, которое жёстко задаёт чужой системный пакет/компонент, или обход недоступных директорий/подписи Android. Это выясняется по реальным запросам клиента; root и установка системного APK не объявляются обязательными для обычного выбора.
Модуль реализован в общем APK True TV Launcher2.1.4, пакет ru.truetv.launcher, отдельного APK/ключа нет. Нативная проверка проводится на отдельном клиенте без разрешения хранилища при отключённом DocumentsUI: реальное чтение/запись, URI после перезапуска, несколько файлов, дерево и запрет доступа к соседнему документу. Это не гарантия работы приложений с жёстко заданным чужим компонентом. Для обычных файлов не нужны root/ADB. Android30+ требует ручного доступа ко всем файлам и закрывает Android/data/obb. Физический USB/OEM/конкретные эмуляторы проверяются владельцем по чек-листу.
Wi-Fi-передача отложена владельцем. Только видимый пункт «Передача по Wi-Fi — позже»: нет сервера, обнаружения устройств, фоновой передачи и телефонного ассистента. Архивация папок пока не реализована; отправка — для выбранных файлов через системный список приложений.

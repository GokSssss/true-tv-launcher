Файловый менеджер0.2 — управление пультом
Три состояния одной уточнённой схемы. Это изображения концепций, не работающий APK.

01. Основной экран
Слева дерево хранилищ/папок, справа только строки выбранного каталога. В строке значок, имя с кратким описанием, ⋮ и галочка. Текущая папка и настоящий фокус пульта визуально различаются. Нижних карточек/операций нет.

02. Меню долгого нажатия
Все действия в одном popup около текущего файла: Копировать, Вырезать, Вставить, Переименовать, Удалить, Отправить, Выделить всё, Свойства, Отмена. Тот же popup открывает ⋮. Пустая папка имеет меню папки через дерево/верхнюю ⋮, чтобы вставка/создание работали без фиктивного файла. Меню не требует дойти до конца списка. Изображение демонстрирует непустой буфер, поэтому Вставить не серое; реальная доступность зависит от состояния/прав.

03. Выбор для другого приложения
Пример запроса, разрешающего несколько документов: два файла отмечены, счётчик и подтверждение «Выбрать (2)» сверху. Это не нижняя панель файловых действий. При одиночном запросе множественные галочки не показываются. Для доступа к шапке предусмотрен быстрый переход от крайнего правого элемента строки, возврат сохраняет позицию.

Кнопки
Стрелки переводят фокус по дереву/строкам и элементам строки. OK открывает файл/папку или переключает галочку. Долгий OK и ⋮ дают одно меню, без одновременного открытия файла. Назад закрывает меню/возвращает к родителю. Меню циклическое. «Выделить всё» относится к текущей отфильтрованной выборке, включая ещё не прокрученные строки. Отметка не равна фокусу.

Провайдер
Требуются собственный DocumentsProvider и собственный picker для обычных Android-запросов, чтобы обслуживать приложения наTV без DocumentsUI. Сам по себе провайдер не создаёт отсутствующее окно выбора. В0.2-Выбор-файлов-и-провайдер.txt описаны контракты и будущая приёмка. Успешный возврат URI/допусков после перезапуска ещё не реализован и не тестировался. Приложения, задающие чужой системный компонент явно, требуют отдельной совместимости.

Изображения0.1 больше не являются действующей схемой: нижние действия/карточки и отсутствие дерева отклонены владельцем. Они сохранены как предыдущая итерация; первый0.1 использован только как визуальная основа стиля. В текущих0.2 три независимых состояния, не три конкурирующих варианта. Содержание файлов/числа/даты иллюстративные. Исходные PNG генератора сохранены, промпты и путь референса рядом; точная повторная генерация не обещается.

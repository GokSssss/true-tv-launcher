# To TV 1.0.2

Ассистент Android5+ (min21/target34), ru.truetv.totv. Появляется только в меню Отправить/Share, нет отдельного лаунчерного значка или собственного менеджера файлов. Выберите файлы → To TV → телевизор. На TV заранее откройте значок папки с плюсом и Wi-Fi рядом с файловым менеджером. При закрытом окне TV не обнаруживается и не принимает файлы. Подтверждение приёма — на TV, если не включена галочка «Принимать без подтверждения».

Прогресс — на телефоне и TV. content:// URI с ClipData передаются явно запущенной foreground-службе; широкий доступ к хранилищу не нужен. TLS проверяет текущий выбранный mDNS-ключ, нет доверенных списков/первого кодового диалога. Поток64KiB и SHA256, незавершённый файл не публикуется. Исходные файлы не удаляются. Одновременный приём и отправка на одном физическом TV не поддерживаются: открытие отправителя закрывает TV receive window.

Сборка: python3 tools/build-phone.py, результат artifacts/1.0.2-To-TV.apk. Общие bridge исходники в едином SOURCE проекта22.1; private signing/cache отдельно. Собственный протокол, совместимость File2TV не заявлена.
